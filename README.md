## 三、数据口径与勘误（核查要点）

数据来源：《水产批发市场明细.xlsx》Sheet1（30 行），与 Sheet2 汇总表核对一致（规划开店合计 **943 家**）。

| 项目 | 处理 |
| --- | --- |
| 经纬度 | 采用「标注名称」组坐标；原表「市场名称」组坐标存在逐行错位（自第 7 行起），已弃用 |
| 城市勘误 | `无心` → 无锡；`河南` → 郑州 |
| 名称勘误 | site_id=23 原表以地址登记，规范名称为「成都通威三联水产品市场」（成洛大道 5999 号），档案中已注明 |
| 级别 | 一级 25 座（区域/城市主导集散）· 二级 4 座（产地收购 / 城市分销）· 三级 1 座（城区终端零售） |
| 能力等级 | 按台账「规划开店容量」推算：S≥60（5 座）· A≥40（6 座）· B≥20（3 座）· C<20（16 座） |
| 置信度 | 每条规模数据标注来源与置信度（高/中/低），产地型市场标注「待实地复核」 |

公开资料核查要点：

- 广州黄沙：日均约 600 吨供应全国（广州市政府，置信度高）
- 杭州新农都：年成交额 70 余亿元，浙江鲜活水产源头市场（官方行业协会，置信度高）
- 昆明骏骐：旺季日交易额超 5000 万元（官方报道，置信度高）
- 江门远恒：珠江西岸最大水产产业综合体（开业报道）
- 天津王顶堤：年交易额百亿级（历史口径，置信度中）
- 福州海峡：全国最大水产品交易中心（央视报道，置信度中）

完整来源清单见页面「核查方法」区。

## 四、页面特性

- **WebGL 深海潮汐 Hero**：FBM 域扭曲波浪着色器，月光随鼠标偏移，波峰泡沫与暗角颗粒；无 WebGL 自动降级为静态渐变
- **全国分布地图**：34 省级边界 SVG + 30 个脉冲光点；悬停显示工具提示并**高亮该市场辐射省份**（按台账覆盖城市列表映射）；点击进入档案
- **市场名录**：搜索 + 城市 / 级别 / 品类筛选 + 门店容量排序；卡片 3D 倾斜、光斑跟随
- **档案抽屉**：供应能力画像、规模指标（含来源与置信度）、供应品类、覆盖城市、规划开店容量、核查结论、高德导航 / 复制坐标
- **全局动效**：预加载潮汐仪式、字符级标题入场、计数缓动、环形/条形图表、磁吸按钮、自定义光标、胶片颗粒、滚动进度、平滑视差
- **工程健壮性**：IntersectionObserver 兜底强制显现（防白屏）、深链直达、键盘可达（Esc/Enter）、`prefers-reduced-motion` 降级、无 JS 兜底、无外部运行时依赖
